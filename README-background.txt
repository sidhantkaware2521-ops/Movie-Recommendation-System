OPTIONAL CINEMATIC BACKGROUND VIDEO
-----------------------------------
Place a licensed MP4 video named `background.mp4` in this folder:
  public/background.mp4

The website uses it as a muted, full-screen, continuously looping background.
Use your own video or a video you have permission to use. Keep the file reasonably
small (ideally 5–15 MB) and encode it as H.264 MP4 for broad browser support.

If no file is present, the animated dark-purple gradient and poster artwork still
make the site work. The background video is decorative and muted to support autoplay.
